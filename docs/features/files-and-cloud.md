# Files

Browse remote files over SFTP/SCP or SMB. Upload and download files and folders,
rename, delete, create directories and copy between connected hosts. Multi-select,
transfer progress, conflict handling and interrupted-copy recovery are supported.

SSH file access can fall back from SFTP to SCP. Permission and ownership editing
are available where the backend supports them. The built-in text editor provides
syntax highlighting and find/replace; other files can open in an external app.
Android local folders remain available for transfers through the system file picker.

Cloud providers, cloud synchronization, media conversion, streaming servers and
image editing are not included.
