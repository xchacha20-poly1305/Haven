# Features

This build focuses on remote connections. Built-in VPN clients, email, local
Linux runtimes, AI/MCP, cloud storage, mesh networking, OCR, media processing
and image editing have been removed.

- [Terminal](features/terminal.md): SSH, Mosh, Eternal Terminal and serial consoles.
- [Remote desktops](features/desktops.md): VNC, RDP, SPICE and GLKVM / PiKVM.
- [Files and cloud storage](features/files-and-cloud.md): SFTP/SCP and SMB.
- [Connections and networking](features/connections.md): SSH forwarding, jump hosts,
  SOCKS/HTTP proxies, port knocking and SPA.
- [USB forwarding](features/usb.md): USB/IP and SPICE redirection to remote hosts.
- [Security](features/security.md): encrypted backups, key management and biometric lock.
